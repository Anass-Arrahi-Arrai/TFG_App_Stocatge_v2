Bienvenido al repositorio del proyecto de **Software de Gestión de Estocaje para Pastisseries PIMEs**, desarrollado como parte del Trabajo Final de Grado (TFG) en Ingeniería Informática de Gestión y Sistemas de Información. Este proyecto tiene como objetivo optimizar la gestión de inventarios y comandas en pastisseries de pequeña y mediana empresa (PIMEs), mejorando la eficiencia operativa y reduciendo errores administrativos.

---

## 📌 Resumen del Proyecto

El software desarrollado es una aplicación móvil diseñada para **pastisseries PIMEs** que permite gestionar de manera eficiente el inventario, realizar comandas a proveedores, y generar informes estadísticos para la toma de decisiones estratégicas. La aplicación está construida con **Flutter** y utiliza **Hive** como base de datos local, lo que garantiza un rendimiento rápido y una experiencia de usuario fluida.

### Características principales:
- **Gestión de Inventario:** Control de stock, actualización de existencias y seguimiento de productos perecederos.
- **Comandas a Proveedores:** Creación, modificación y seguimiento de comandas.
- **Estadísticas y Reportes:** Generación de informes de tendencias de compra, rendimiento de proveedores y más.
- **Interfaz Intuitiva:** Diseño responsive y fácil de usar, optimizado para dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

- **Flutter**: Framework de desarrollo multiplataforma para crear aplicaciones móviles.

---

## 📂 Estructura del Proyecto

El proyecto está organizado en los siguientes directorios principales:

- **`lib/`**: Contiene el código fuente de la aplicación.
  - **`pages/`**: Páginas principales de la aplicación (gestión de inventario, comandas, proveedores, etc.).
  - **`models/`**: Definiciones de los modelos de datos (proveedores, productos, comandas, etc.).
  - **`repositories/`**: Clases que gestionan las operaciones con la base de datos.
  - **`components/`**: Componentes reutilizables de la interfaz de usuario.
  
- **`assets/`**: Contiene imágenes, iconos y otros recursos visuales.
- **`test/`**: Pruebas unitarias y de integración.

## 📊 Análisis de Resultados

El software ha demostrado ser eficaz en la mejora de la gestión de inventario y comandas en pastisseries PIMEs. Algunos de los resultados clave incluyen:

- **Reducción del 30%** en errores administrativos.
- **Disminución del 25%** en rupturas de stock.
- **Mejora del 40%** en el tiempo de procesamiento de comandas.
